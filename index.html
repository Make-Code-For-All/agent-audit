Agent Audit

Paste a public GitHub repository. This page reads its files without ever running them, then reports risky code patterns, suspicious dependencies and repository red flags.

Public repositories only, any size, nothing to install or sign in to. The whole repository is downloaded from GitHub through this site’s scan service and analysed in your browser; the service only passes the download along and keeps none of it.

Optional settings

You do not need one. It is only a backup for when this site’s scan service is unreachable and GitHub’s limit for anonymous visitors (60 requests per hour) has run out. Use a token with no permissions. It is kept in memory, sent only to api.github.com, and cleared when you reload the page.

    What this scan can and cannot tell you

    • It looks for known risky patterns: dynamic code execution, download-and-run commands, credential file access, exfiltration endpoints, persistence tricks, obfuscation, hidden characters and text aimed at AI reviewers.
    • It checks npm and PyPI dependencies in package.json and requirements*.txt against the OSV.dev database, including its list of known malicious packages, and flags names that look like typos of popular packages.
    • It cannot see code that is downloaded after install, payloads that activate later, or heavily obfuscated logic. A clean result means nothing was found, not that the repository is safe.
    • The deep scan runs Semgrep, secret detection and dependency audits on GitHub’s servers, still without executing the repository’s code. The repository link and commit are sent to this site’s scan service, and results are kept for 24 hours and then deleted.
    • Everything in the scanned repository is treated as hostile text. It is displayed as plain text only and never executed or interpreted.
